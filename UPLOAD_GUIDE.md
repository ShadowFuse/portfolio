# How to publish

The supplied site is a redesigned GitHub Pages portfolio, not the source code for Pluvia or Form. Their cards use CSS-generated illustration previews. The Dobro visual is the screenshot supplied in the conversation.

1. Back up the existing `ShadowFuse/portfolio` repository (or create a new branch).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder into the root of `ShadowFuse/portfolio` on its `main` branch. Old assets may remain until the site is checked.
3. Confirm GitHub Pages is publishing the `main` branch, root directory. Visit https://shadowfuse.github.io/portfolio/ .
4. In `ShadowFuse/ShadowFuse`, replace the root `README.md` with the contents of `PROFILE_README.md` (rename it to `README.md` during upload).
5. Upload the actual Pluvia and Form project ZIP archives to this chat so source repositories and working demo links can be created. After verification, replace the temporary status text on the cards with those links.
6. If you have permission to display the medical site case, link its public demo or repository if one exists; do not assert that a concept is a completed commissioned deployment without evidence.
