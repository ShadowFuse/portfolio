# PLUVIA — Дождь

Интерактивная сцена: дождь над лесом, запотевшее стекло и капли, которые можно стирать курсором или касанием.

## Файлы

В архиве index.html, style.css, три JavaScript-файла, assets/forest-canopy.webp и audio-credits.html. Это исходники и готовый статический сайт: сборка и npm не нужны.

## Запуск

Распакуйте архив. Для локального просмотра откройте терминал в папке с index.html и выполните:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. На Windows можно использовать `py -m http.server 8000`.

## Публикация

Загрузите содержимое папки на любой статический хостинг. index.html должен находиться в корне публикации. Для GitHub Pages положите файлы в корень репозитория и выберите публикацию из этой ветки в Settings → Pages. В исходном репозитории Sites эти файлы лежат в dist/.

Все пути к собственным файлам относительные: сайт можно разместить и в подпапке портфолио.

## Управление

Курсор или касание стирают капли и запотевание. Внизу — три силы дождя, плотность запотевания и очистка волной. Звук включается вручную справа сверху. «Скрыть интерфейс» включает погружение; кнопка «Вернуться» или Escape возвращает интерфейс.

## Внешние ресурсы и авторство

Для аудио и веб-шрифтов требуется интернет: три записи загружаются с Wikimedia Commons, шрифты — с Google Fonts. Эти ресурсы не включены в архив. Если Google Fonts недоступен, используются системные шрифты.

Авторство и лицензии аудиозаписей указаны в audio-credits.html; сохраните эту страницу и ссылку на неё при публикации. Аудиофайлы используются без изменения. Изображение леса создано генератором изображений.

Визуальная сцена реализована на Canvas 2D; WebGL и сервер приложения не требуются.
